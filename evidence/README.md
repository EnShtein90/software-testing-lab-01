# 

\### 1. Можно ли начинать реализацию по исходным требованиям без уточнений?



Нет, сначала необходимо уточнить спорные моменты. Например, какие возрастные ограничения действуют, как должна работать регистрация при повторном нажатии кнопки и какие данные пользователя можно показывать при занятом email. Иначе разработчики могут неправильно реализовать функцию.



\### 2. Какие три риска требуют первоочередного тестирования?



1\. Неправильная проверка возраста — система может отклонять пользователей, которые соответствуют требованиям.

2\. Создание нескольких аккаунтов — при двойном нажатии кнопки регистрации могут создаваться дубликаты.

3\. Утечка персональных данных — система может раскрывать информацию о пользователе при попытке зарегистрироваться с уже занятым email.



\### 3. Какие проверки следует автоматизировать в первую очередь?



В первую очередь стоит автоматизировать:



\- Проверку корректности введённых данных.

\- Проверку возраста пользователя.

\- Проверку уникальности email.

\- Проверку успешной и неуспешной регистрации.

\- Проверку повторного нажатия кнопки регистрации.

\- Проверку обработки ошибок.



Это позволит быстрее находить ошибки при каждом изменении программы.



\### 4. Какие проверки требуют участия человека?



Участие человека необходимо для:



\- Проверки удобства и понятности интерфейса.

\- Оценки правильности и понятности сообщений об ошибках.

\- Проверки доступности интерфейса для разных пользователей.

\- Оценки удобства процесса регистрации.

\- Проверки внешнего вида на разных устройствах.



\### 5. Какие сведения необходимы для определения готовности функции к выпуску?



Для принятия решения о выпуске необходимо знать:



\- Все ли требования выполнены.

\- Пройдены ли основные тесты.

\- Остались ли критические и серьёзные ошибки.

\- Устранены ли проблемы с персональными данными и безопасностью.

\- Работает ли регистрация без сбоев.

\- Есть ли результаты тестирования и подтверждающие материалы.



Вывод: функцию можно выпускать, если основные требования выполнены, критические ошибки устранены, персональные данные защищены, а результаты тестирования подтверждают стабильную работу регистрации.
